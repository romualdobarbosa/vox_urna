# Seções que violam invariantes vão para quarentena, não derrubam o pipeline

No silver, uma seção que viola uma invariante (a soma dos votos é diferente do comparecimento, aptos é diferente de comparecimento + abstenção, ou a seção está duplicada) vai para uma tabela de rejeitadas, e o build continua. O build só falha se as rejeitadas passarem de 0,1% das seções do turno. Os dados reais do TSE podem ter poucas seções inconsistentes, e isso não deve travar a entrega. Já uma taxa alta indica um erro sistêmico nosso (por exemplo, no parsing ou no filtro de cargo), que não pode passar em silêncio.
